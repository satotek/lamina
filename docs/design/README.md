# Lamina 設計ドキュメント

Lamina は Rust と GPUI で構築された軽量・クロスプラットフォームの Git クライアントである。大規模リポジトリでも高速に動作すること、Git の正確な挙動（フック、署名、認証ヘルパー、設定、LFS など）を維持すること、UI 非依存のコアと GPUI ベースの UI レイヤーを明確に分離することを設計の軸としている。本ディレクトリでは、ワークスペース全体のアーキテクチャおよび各クレートのモジュール設計をまとめる。

| ドキュメント | 対象 | 概要 |
| --- | --- | --- |
| [architecture.md](architecture.md) | 全体アーキテクチャ | 設計目標・非目標、クレート構成と依存方向、`gix` 読取 / `git` CLI 書込の方針、スレッド・データフロー、エラー設計、テスト戦略、プラットフォーム固有事項 |
| [core.md](core.md) | `lamina-core` | リポジトリ読取（`repo/`）、`git` CLI 実行（`git_cli/`）、セッション調停（`session/`）、グラフレイアウト（`graph/`）、差分・パッチ・マージ・ハイライト等のモジュール別設計 |
| [app.md](app.md) | `lamina-app` | GPUI UI レイヤー（ビュー構成、仮想化リスト、グラフ描画、状態管理、キーマップ、コマンド・設定 UI） |
| [terminal.md](terminal.md) | `lamina-term` / ターミナルパネル | `lamina-term`（`libghostty-vt` + `portable-pty` ベースの UI 非依存ターミナルコア）と組み込みターミナルパネル |
